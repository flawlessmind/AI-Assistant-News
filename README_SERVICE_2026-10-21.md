### Исправление диагностики LLM от 21 октября

Подтверждённая причина: finish_reason=length, completion_tokens=reasoning_tokens=1800 и пустой content. Черновик теперь имеет предел 6144 токена, review — независимые 4096, timeout — 120 секунд. В .env изменены только эти три настройки; ключ сохранён. Дословные цитаты и даты проверяются, незавершённый JSON не восстанавливается. Review имеет отдельное задание и передаёт конкретные замечания следующему раунду. Обновлённые новости по-прежнему не откатываются при старте. Разовый установщик удалён: изменения находятся в основных файлах.

## Быстрый запуск без ключа

Нужен Python **3.12.14** с SQLite FTS5. Основной сервер, HTTP-клиент и RSS используют стандартную библиотеку, интерфейс — обычный HTML/CSS/JS. Установка пакетов для основного сценария не требуется. pypdf в requirements.txt нужен только для повторного извлечения уже обработанных PDF.

Из корня проекта:

```powershell
python -X utf8 -m alfa_app serve --port 8000
```

Открыть **http://127.0.0.1:8000**. При старте загружается data/news_snapshot.jsonl — снимок реальных текстов, позволяющий проверить интерфейс без сети. «Обновить источники» читает настоящие RSS и статьи; LLM при этом не вызывается.

Неизменённые HTML/XML первоисточников сохранены в data/news_sources/ с SHA-256 в именах. manifest.json связывает их со снимком статей и отчётом повторной загрузки. Интерфейс показывает извлечённый текст; исходный HTML не исполняется.

```powershell
python -X utf8 -m alfa_app refresh --limit 5 --export-snapshot
```

--limit допускает 1–15 статей из каждого канала. Загрузчик не привязан к заданным ID; новые публикации попадут при следующей загрузке. Ошибки источников возвращаются отдельно, вымышленные статьи при ошибке не создаются. Дата события отдельно не угадывается: если не установлена, event_date=null.

## Настройка ключа команды или экспертов

Создать локальный .env, сохранив существующий:

```powershell
if (-not (Test-Path -LiteralPath '.env')) { Copy-Item -LiteralPath '.env.example' -Destination '.env' }
```

Заполнить **локально**, не в чате и не в браузерном коде:

```dotenv
ALFA_LLM_BASE_URL=https://changellenge.up.railway.app/v1
ALFA_LLM_API_KEY=ключ_из_письма_организаторов
ALFA_LLM_MODEL=deepseek/deepseek-v4.1-flash
ALFA_ALLOW_LIVE_LLM=true
ALFA_LLM_MAX_OUTPUT_TOKENS=6144
ALFA_LLM_REVIEW_MAX_TOKENS=4096
ALFA_LLM_TIMEOUT_SECONDS=120
```

Перезапустить сервер. Кнопка «Сформировать с LLM» станет доступной. Это разрешение конфигурацией, а не доказательство доступности API. Эксперты подставляют свой ключ; ключ команды в сдачу не включается.

Проверка конфигурации **без сети и расходов**:

```powershell
python -X utf8 -m alfa_app.llm probe
```

Отдельная небольшая платная проверка — **только при явном --live**: читает /key/info и выполняет один короткий Chat Completions-запрос:

```powershell
python -X utf8 -m alfa_app.llm probe --live
```

Ровно шесть разрешённых model ID:

```text
google/gemma-4-26b-a4b-it
z-ai/glm-5.3-flash
qwen/qwen3.6-35b-a3b
deepseek/deepseek-v4.1-flash
qwen/qwen3-vl-30b-a3b-instruct
moonshotai/kimi-k2.6
```

Используется OpenAI-compatible HTTP /v1/chat/completions. SDK openai разрешён организаторами, но в этой версии клиент написан на стандартной библиотеке. Streaming, function calling и strict JSON schema не предполагаются: JSON проверяется после ответа.

## Бюджет

Официальный предел — **500 ₽ на общий ключ в сутки**, сброс **03:00 Europe/Moscow**. Старое 00:00 отменено новой инструкцией. Дата периода — московское время минус три часа. Тесты проверяют переход 02:59:59 → 03:00.

Цены моделей и единицы /key/info неизвестны: токены не переводятся в придуманные рубли. Дополнительный локальный предел — 30 запросов на период для всех моделей с данным ключом; **он не эквивалентен 500 ₽**. Денежный предел обеспечивает шлюз. Другие участники и установки приложения могут тратить тот же ключ вне этого локального счётчика.

Budget has been exceeded блокирует генерацию до следующего периода. Авторизация не повторяется; сеть и временные HTTP-ошибки имеют максимум один повтор. Кеш учитывает ключ, модель, промпт и полный контекст компании/роли/новости/доказательств. Счётчик резервируется транзакционно. В публичных ошибках нет ключа и исходного тела ошибки шлюза. Usage сохраняется, стоимость остаётся неизвестной.

## Агентный цикл

План зависит от тем новости, профиля и вопроса. Сначала выбирается подходящее исследование, затем возможен более широкий поиск. В модель передаются максимум шесть фрагментов, а не все CSV/PDF. LLM возвращает отдельно факты, мнение банка, условную интерпретацию, риски, возможности, действия и неопределённость.

Локальная проверка отклоняет отсутствующие цитаты, неизвестные evidence_id/поля компании, неподтверждённые числа и безусловные последствия. Числовые выводы из непроверенного банковского OCR запрещены. Дополнительный вызов разрешённой модели проверяет смысловую опору, противоречия и персонализацию; это модельная проверка, не гарантия истинности.

При замечаниях агент меняет поиск и передаёт их следующему черновику. Четыре опорных фрагмента сохраняются, до двух других дополняют контекст. Частные договоры компании не ищутся в публичной макроаналитике: это неизвестные данные и вопросы клиенту. По умолчанию два раунда. При провале — «недостаточно данных», без публикации черновика. Trace и безопасные метаданные сохраняются в var/service.sqlite и видны в карточке.

## Сквозная проверка

1. Выбрать U_1595 и войти в новостную аналитику с главного экрана.
2. Открыть «В большинстве регионов в сентябре цены выросли умеренно» от 16.10.2026 — новую для проекта реальную статью.
3. Проверить причины по ОКВЭД и кредитному маркеру, открыть OCR страницы и PDF. Дата банковского документа указана отдельно от новости.
4. Выбрать U_83932: прежняя карточка сбросится, оценки/причины изменятся. Нулевой кредитный маркер не называется отсутствием заимствований.
5. С ключом запросить генерацию; без ключа увидеть отключённую генерацию и работающие источники.
6. Задать уточняющий вопрос: в режиме источников он меняет поиск, с LLM проходит новый проверяемый цикл.
7. Дважды обновить RSS: одинаковые статьи не размножаются. Для невиданной новости обновить позже или увеличить --limit.

Служебные анонсы конференций и календарные сообщения не получают высокий балл только из-за упоминания ставки. Через «Все события» они остаются доступными.

## Docker и тесты

```powershell
docker compose up --build
```

Открыть http://127.0.0.1:8000. .env/окружение читаются при запуске; секрет не копируется в образ. Индекс и снимок доступны сразу. Кеш, новости и trace сохраняются в томе alfa-runtime. Образ закреплён версией/digest; процесс непривилегированный. Повторный OCR не нужен.

```powershell
python -X utf8 -m unittest discover -s tests -v
python -X utf8 check_corpus.py
docker compose run --rm alfa-news python -X utf8 -m unittest discover -s tests -v
docker compose run --rm alfa-news python -X utf8 check_corpus.py
```

Версии: .python-version и runtime.lock.json. Основной runtime не имеет сторонних Python-зависимостей. Прежний OCR с Windows и альтернативная непроверенная ветка Tesseract не входят в основной контейнер.

## Ограничения и сдача

Реальная банковская сессия не подключена: компания и роль выбираются в синтетическом демо-контексте. Ключ только на backend. Внешние данные отделены от системной инструкции; модель не может выполнять команды/передавать URL инструментам. UI использует textContent и CSP, изменяющие запросы — same-origin action token. Для промышленного размещения потребуются полноценная авторизация и инфраструктурная защита.

Живой сценарий проверен для одной разрешённой модели и одной новости. Другие пять моделей, цены, технические возможности JSON mode/thinking и качество на размеченной выборке не проверены. Лексический поиск и OCR имеют ошибки. Два RSS-канала принадлежат одному издателю — Банку России. Профилей в демонстрации два, банковский корпус датированный и автоматически не обновляется.

Актуальная проверка живой генерации: data/generation_verification_2026-10-21.json и docs/LLM_FIX_VERIFICATION_2026-10-21.md. Прежние data/service_verification_2026-10-21.json и docs/ALFA_STATUS_2026-10-21.md — исторический срез до настройки ключа. Маленькие проверки не являются статистической оценкой RAG. Исходное обновление и инструкция организаторов сохранены в docs/.
