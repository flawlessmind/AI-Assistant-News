# Обновление данных

## Новости

Три публичных канала: [новости Банка России](https://www.cbr.ru/rss/eventrss),
[пресс-релизы Банка России](https://www.cbr.ru/rss/RssPress),
[новости Росстата](https://rosstat.gov.ru/folder/313/rss).
Росстат публикует ссылку RSS в [разделе новостей](https://rosstat.gov.ru/folder/313/).
Он добавлен для отраслевой статистики и отчётности, а не как независимое подтверждение
того же сообщения Банка России. Это два издателя, не три независимых источника.

Публичный RSS даёт адрес, заголовок и время публикации; затем читается тело статьи.
В содержательном RSS допустимо использовать текст самого издателя с соответствующей
пометкой. Если текста нет, новость из одного заголовка не создаётся. Неверный HTML,
CAPTCHA, неизвестный адрес и будущая публикация не превращаются в новость.
Издатель, URL, даты, SHA-256 и исходный XML/HTML сохраняются. При редиректе допустим
только тот же издатель из HTTPS-списка; ключ LLM к этим запросам не прикрепляется.
Параметр limit ограничивает число элементов каждого канала. Автоопрос в фоне отсутствует;
обновление запускается кнопкой или CLI. Правила издателей проверять при добавлении каналов.

Повторный импорт сохраняет исправления заголовка, даты и происхождения даже при прежнем
текстовом SHA-256. Запись и дедупликация атомарны; ID и история не меняются. Одно изменение
retrieved_at считается duplicate, но время сохраняется. Технические хеши исходников не
сбрасывают кеш анализа; заголовок/даты входят в контекст и при исправлении требуют новой
проверки. Модель автоматически при импорте не вызывается. Исходные XML/HTML сохраняются
по собственным хешам, поэтому изменение метаданных не удаляет прежний источник.

23.10.2026 обычная загрузка получила шесть статей из трёх RSS без ошибок: четыре отдельных
HTML и два содержательных RSS. Отчёт — `data/final_refresh_2026-10-23.json`.
В фиксированной дополнительной выборке 32 полных статьи ЦБ и 8 Росстата, отдельно от
исходных десяти; исходный снимок не изменён. Одна отклонённая страница ЦБ отмечена
в provenance, вместо неё взят следующий настоящий материал. Полные HTML хранятся
локально; в поставке тексты с атрибуцией, хеши и два исходных RSS.

HTTPS-проверка включена. На этой Windows доверие управляемому HTTPS-прокси в Python
отличается от системного. При SSLCertVerificationError используется штатный curl.exe,
без отключения проверки, автоматических редиректов и shell. Если в сети Linux есть
TLS-инспекция, оператор может задать её CA: `ALFA_NEWS_CA_BUNDLE=/путь/ca.pem`, только для загрузчика новостей.
Личные сертификаты в Git/ZIP/образ не включаются. В обычной сети дополнительных CA не нужно.
Переменная не влияет на авторизованный транспорт LLM.

У Росстата сервер отдаёт только конечный сертификат с AIA промежуточного CA версии 2024.
Для Linux в комплект включена публичная цепочка Russian Trusted Root CA и Russian
Trusted Sub CA 2024. Корень сверён с HTTPS-файлом Госуслуг, промежуточный сертификат
получен по AIA и проверен подписью в реальном HTTPS-сеансе. Происхождение, сроки и хеши —
`data/certificates/rosstat-ca-provenance.json`. Байты цепочки закреплены SHA-256.
Она загружается только в отдельный TLS-контекст разрешённых адресов Росстата. Проверки
имени хоста, срока и подписи обязательны; системное доверие и транспорт LLM не меняются.
В Linux реально получены RSS из 20 элементов и полная статья из 5285 символов.
При ротации промежуточного CA обновить цепочку после проверки издателя, а не отключать TLS.

## Компании и связи

`scripts/build_profiles.py --data-dir ПУТЬ` пересобирает пять производных профилей из трёх
предоставленных CSV. Происхождение фиксируется SHA-256 до/после; исходники не меняются.
Новые профили: производство металлоконструкций U_87, грузовые перевозки U_768,
неспециализированная оптовая торговля U_84. Прежние поля двух исходных профилей сохранены.

Отрасли платёжных связей рассчитаны по уникальным внешним контрагентам. Самопереводы
исключены; отсутствующие, конфликтующие и неклассифицированные записи посчитаны отдельно.
Список крупнейших отраслей не равен долям денег, поставкам или продажам. GROUP_ID даёт
перечень связей набора, но не доказывает контроль, консолидированную выручку или права
выбранного пользователя. Единицы выручки и период платежей не придуманы.

## Банковский корпус

Новые документы сначала сверяются с издателем: подлинность, дата публикации, наблюдаемый
период, физические страницы и оговорки. Подготовить manifest и OCR JSONL существующим
`alfa_research.py`. Не назначать неизвестной дате сегодняшнюю дату. Затем выполнить:

```powershell
.\.venv\Scripts\python.exe -X utf8 scripts/update_bank.py --manifest data/research_manifest.json --pages data/research_pages.jsonl --output-dir var/bank/2026-10-24-review
```

Используется новая папка, существующая отклоняется. Проверяются инвентарь источников,
даты, страницы, структура, точная цитата и соответствие E5-индекса. Если доступны исходные
PDF, добавить `--pdf-dir ПУТЬ` — SHA-256 каждого файла должен совпасть с manifest.
Без этого режима совпадение PDF-файлов не объявляется проверенным. Числа OCR всё равно
требуют визуальной сверки; точное вхождение цитаты не доказывает смысловой вывод.

Протокол сохраняется в validation.json. После просмотра результатов явно установить
`ALFA_RESEARCH_DATABASE=.../research.sqlite` и перезапустить сервер. Новый fingerprint
отзывает старые approvals; история сохраняется. Откат — вернуть путь прежнего корпуса
и перезапустить. Самостоятельного сбора новых PDF и автоматической подмены позиции банка нет.

23.10.2026 исходный корпус реально пересобран в отдельную runtime-папку: 9 документов,
64 страницы, 131 фрагмент и 74 поисковых вектора. Активные индекс и OCR сохранены.
