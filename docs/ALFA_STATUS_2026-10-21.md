## Запуск

Распаковать новую версию, открыть каталог alfa_service и выполнить с Python 3.12.14:

```powershell
python -X utf8 -m alfa_app serve --port 8000
```

Открыть http://127.0.0.1:8000. Без ключа доступны новости и банковские источники. Генерация отключена и не имитируется. После проверки временный сервер агента остановлен; приложение запускается этой командой.

API команды при разработке и проверках не вызывался. Прежний FIRST_INSIGHT.md — вручную подготовленный исторический образец, а не сгенерированный результат новой версии.
