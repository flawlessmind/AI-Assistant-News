## Причина остановленного запуска

`7198477162aa450abd3df744430e09d8`, 12:06:28 МСК: U_1595, cfo, вопрос «Каких данных не хватает для полного вывода?», дата анализа 21.10.2026, логика `2026-10-21-v6-review-feedback`. Хеш текста новости: `69bf1695dd7660b00c101abfab44b8dcf9ebb793c2abdc5978b01fae5fe238be`.

Соседний успешный экран — другой запуск `488a7e7fa84b4065aa32ce8fb75b5359`, 12:03:35, без уточняющего вопроса. Его готовый ответ брался из кеша. Эти экраны нельзя считать одним запуском.

Остановленный запуск сделал три запроса: draft → review отклонил предположение о текущем кредите → новый draft. Все три завершились `stop`, не `length`. В последнем ответе цитата была приписана другому фрагменту той же страницы (`ev_7ae7338fd2d2dcb274ec0b69`), а действие ссылалось на несуществующий ID `ev_544ad1c4cf24ded425d16c3`. Публикация правильно остановлена. Надпись «недостаточно доказательств» неточно описывала ошибку ссылок.

Корневая ошибка маршрутизации: вопрос о пробелах заставляли заполнять все разделы инсайта и обязательный риск. Вопрос добавлялся в конец плана, затем отсекался ограничением числа запросов. Теперь он задаёт тип задачи; неизвестные продажи и долг не мешают перечислить недостающие данные. Частные условия договора не ищутся в макроаналитике.

## Изменения в основных файлах

- `alfa_app/evidence.py`: полные страницы, сегмент/период, вид утверждения, ограничения переноса; контроль заголовка и summary. Дословность цитат и запрет непроверенных финансовых чисел сохранены.
- `alfa_app/tasks.py`: маршрутизация insight/explain/missing_data/sources и конкретные пробелы по отрасли/роли без LLM.
- `alfa_app/agent.py`: отдельное компактное задание пояснения, раздельные состояния, конкретные замечания и исправление без ненужного поиска; fingerprint загруженной логики и полного контекста.
- `alfa_app/store.py`, `server.py`: актуальный кеш результата по fingerprint; старые approvals возвращаются как stale_result. Прежний полный JSON может быть только непроверенным кандидатом для текущей проверки и нового review. Обрывы JSON для этого непригодны.
- `web/app.js`, `styles.css`: понятные названия признаков, кредитный маркер не равен долгу, видимые границы вывода, раздельные состояния/следующий шаг, содержимое trace и кеш. Готовые ответы повторно открываются без API, в том числе после перезагрузки и при достигнутом локальном пределе.

Во время проверки пояснения обнаружены и исправлены ложные отказы: точная дата, период «7М26», год наблюдения и подписанный ОКВЭД ошибочно считались финансовыми числами. Принимаются только проверяемые метаданные источника/профиля. Неверные даты, чужой ОКВЭД, произвольные суммы и непроверенные OCR-показатели продолжают отклоняться. Исправлены ложные отказы на вопросительный заголовок, отрицание прогноза и явную фразу об отсутствии подтверждения. Регрессии покрывают и противоположные, недопустимые формулировки.
