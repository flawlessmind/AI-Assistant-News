# Интерфейс alfa_service · проверка 21–22 октября 2026

Изменена существующая реализация HTML/CSS/JS. Backend, правила доказательств, промпт, API-контракты, ключ, индекс и исходные профили сохранены. Это проверка интерфейса; нового ответа LLM в этой работе нет.

## Инструменты

Найдены существующие Node.js 24.15.0, npm/npx 11.12.1 и Codex CLI 0.147.0. Они не переустанавливались. AGENTS.md в проекте и проверенных родительских папках не найден.

По официальному репозиторию https://github.com/nextlevelbuilder/ui-ux-pro-max-skill выполнено:

```powershell
npx --yes ui-ux-pro-max-cli init --ai codex
```

Установлена одна копия открытого навыка в `.agents/skills/ui-ux-pro-max`: прочитан SKILL.md, проверен локальный поиск Python (37 CSV, 15 Python-файлов). Использованы рекомендации по минимализму, плотности, контрасту, фокусу и раскрытию подробностей. Данные рекламного лендинга из генератора не переносились в сервис. В этой работе SKILL.md применён вручную. Путь также включён в `skills.config` личного config.toml; для появления в автоматически формируемом каталоге навыков можно открыть новый сеанс Codex в папке проекта.

Официальный Playwright MCP: https://github.com/microsoft/playwright-mcp. Codex CLI найден, но `mcp add` не смог создать временный файл в каталоге личной конфигурации. Таблица добавлена непосредственно в реальный `C:\Users\Fedic\.codex\config.toml`; TOML разобран до и после, прежний node_repl и прочие настройки сохранены. Новая таблица:

```toml
[mcp_servers.playwright]
command = "npx.cmd"
args = ["-y", "@playwright/mcp@latest", "--headless", "--isolated", "--browser", "msedge"]
startup_timeout_sec = 60
tool_timeout_sec = 60
```

Сначала запуск отдельных браузеров из изолированного shell завершался ошибками Windows. Затем MCP автоматически появился в текущем каталоге инструментов Codex. Его настоящим browser_navigate открыт http://127.0.0.1:8001/, выполнены browser_resize, browser_run_code_unsafe с тестами страницы, снимки и чтение консоли. Перезапуск Codex для MCP в этом сеансе не потребовался. Дополнительно использован встроенный браузер с документированной возможностью viewport. На 8000 сервис в этой среде не отвечал; проверен работающий 8001.

Инструменты разработки не требуются для Python-сервиса. .agents/.codex/node_modules, отчёты Playwright и резервные копии в .cache исключены из Docker; frontend не использует CDN, внешние шрифты или Node runtime. Тексты MIT и Apache 2.0 сохранены в `docs/licenses/`, сведения — в THIRD_PARTY_NOTICES.md.

## Дизайн и изменения

- Светлый фон, белые поверхности, красный акцент, тёмная кириллическая типографика на системных шрифтах; единые размеры, границы и отступы. Удалены большая боковая панель и декоративная растяжка первого экрана.
- Новости открываются сразу. На широком экране лента слева, анализ справа; на планшете и телефоне блоки складываются. Единственная новость на планшете занимает строку целиком.
- В выборе компании используются короткие названия; полный вид деятельности виден под выбором. Профили остаются синтетическими.
- В карточке раздельны факт новости, датированная позиция банка, явно условная интерпретация и следующее действие. Текст проверенного результата не переписан и не усилен.
- Обоснование релевантности, дословные цитаты, технические признаки, банковские страницы и диагностика раскрываются отдельно. Полные OCR и ссылки сохранены. Показана дата анализа, отличная от даты публикации.
- Убраны повторяющиеся подписи, длинные названия документов в каждой ссылке и повтор вопроса в ответе о пробелах. Полное название источника доступно в банковских карточках.
- Добавлены видимые подписи полей, пропуск к содержимому, состояние выбранной новости, фокус 3 px, обработка пустого вопроса, перенос длинных идентификаторов, reduced-motion/forced-colors и мобильные кнопки от 44 px.
- Исправлена обнаруженная потеря `task` в обработчике повторного запроса: поиск источников повторяется как поиск, с прежним вопросом, без смены задачи на пояснение.
- Встроенная favicon устранила лишний запрос `/favicon.ico` (он давал 400); сторонние изображения не добавлялись.

Открыть http://127.0.0.1:8001/. Если сервер уже работает, обновить страницу; Python-код не менялся. На новом дне готового результата для нового контекста может ещё не быть: режим источников доступен, генерация требует явного запроса и использует бюджет.

До изменения сохранены 8 оригинальных файлов в `.cache/interface-before-20261021`. Для отката frontend из корня проекта:

```powershell
$interfaceBackup = Join-Path (Get-Location) '.cache\interface-before-20261021'
foreach ($relativeFile in @('web\index.html', 'web\styles.css', 'web\app.js', 'tests\test_web.mjs')) {
    Copy-Item -LiteralPath (Join-Path $interfaceBackup $relativeFile) -Destination $relativeFile
}
```

Личная копия прежнего config.toml сохранена отдельно от проекта в `work/design_refresh/before/codex-config.private.toml` рабочего пространства Codex. Она не предназначена для сдачи или публикации. Данные, .env и runtime-БД при откате интерфейса не затрагиваются. Полезные регрессии и изменения находятся в основных файлах, разового установщика или нового слоя hotfix нет.
