# Статус поставки · 22 октября 2026

Приложение сохранено на существующем Python/SQLite/HTML/CSS/JS. Реализован локальный
смысловой поиск новостей и банковских документов; интерфейс, исторические материалы,
пользовательская `.env` и runtime не заменялись. Поставка предназначена для локального
запуска и конкурсной проверки на синтетических профилях. Реальная банковская IAM-сессия
не подключена.

## Реализовано

- Локальный multilingual-e5-small ONNX int8, 384 измерения; веса и tokenizer в комплекте,
  ревизия/SHA-256 закреплены. Данные не уходят во внешний embeddings API.
- Смысловой поиск рассматривает все допустимые фрагменты корпуса, а не только найденные
  по словам. В hybrid участвует и BM25. Исходный OCR/SQLite индекс не изменён.
- `/api/search`, `/api/health`, `doctor`; ошибки отсутствующей модели/устаревшего индекса
  не маскируются лексическим поиском. Поиск в UI с задержкой ввода, защитой от старых
  ответов, повтором после ошибки и сохранением открытой карточки.
- Повтор одного live-анализа блокируется на сервере; готовый результат открывается из
  runtime. Полный прежний JSON может заново проверяться как недоверенный кандидат;
  прежнее одобрение не переносится. Review видит полные страницы всех цитируемых источников.
- Исправлены подтверждённые живой проверкой ложные отказы: «продолжит» в прогнозной цитате
  и ослабление валютного курса в заголовке. Запрет неподтверждённого падения спроса на
  одежду и остальные проверки сохранены.
- Запуск `python -X utf8 scripts/start.py --port 8002` / `START_WINDOWS.cmd`, изолированная
  `.venv`, полный lock зависимостей, pinned image/Compose, сборка ZIP с SHA-манифестом.

- Старый контроль корпуса: 12/12; контроль двух реальных новостей и сочетаний
  компаний/ролей: 13/13, без LLM.

- Настоящий HTTP без ключа: обе компании × обе роли, смысловая новость без совпадения

  `data/ready_http_2026-10-22.json`, `data/audit_quality_2026-10-22.json`.

## Внешние ограничения и сдача

- Docker CLI/Compose доступны, конфигурация проходит `docker compose config --quiet`.
  Docker Engine на этой Windows-машине недоступен: отсутствует pipe
  `dockerDesktopLinuxEngine`. Реальный build/up контейнера не подтверждён; установка
  WSL, изменение глобальной конфигурации или переустановка Docker не выполнялись.
- Оба официальных RSS реально загружаются, но автоматическая загрузка первых полных
  статей получает HTTP 403 от DDoS-Guard. Ограничение сайта не обходилось. Исторический
  снимок и локальный поиск работают; live full-article ingestion остаётся ограничением
  среды. `data/ready_ingestion_2026-10-22.json` содержит наблюдаемый результат.
- Качество на рынке, все шесть генеративных моделей и промышленная банковская интеграция
  не проверены. Числа OCR, валюта/период CSV и текущая задолженность клиента не подтверждены.
- В папке проекта нет `.git`; репозиторий, история, commit/tag и отправка в кабинет не
  создавались этим локальным исправлением. Команде нужен один репозиторий; private открыть
  `alfa-hack-2026`. Для ONNX больше 100 MiB предусмотрен Git LFS либо загрузка закреплённых
  весов скриптом запуска. [Правило GitHub](https://docs.github.com/en/repositories/working-with-files/managing-large-files/about-large-files-on-github).

Готовность локальной сборки не означает, что Docker и все live-сценарии успешно проверены.
Текущие ограничения перечислены для проверки перед конкурсной сдачей.
