# Приёмка приложения · 23 октября 2026

Проверялась актуальная рабочая копия, затем контейнер и отдельно распакованная поставка.
Это инженерная оценка в роли получателя конкурсного решения, не официальная оценка жюри.
Весов критериев в предоставленных материалах нет.

## Результат и изменения после проверки

Приложение запускается на Windows и в Docker, ищет по локальным embeddings, обрабатывает
анализ в фоне и сохраняет задания, результаты и обратную связь. Дизайн сохранён.
Реальные проверки привели к исправлениям:

- Прежний HTTP-сервер заменён Waitress; устранена гонка завершения HTTP-потока в Linux.
- Анализ и обновление RSS вынесены в ограниченную сохраняемую очередь. Перезагрузка
  браузера продолжает чтение задания без новой генерации; компания и роль сохраняются.
- Текст издателя из RSS используется с явным происхождением. Полная статья не понижается
  до короткого RSS при ошибке сайта; заголовки не превращаются в выдуманные статьи.
- Исправлены ложные связи «розничные инвесторы → торговля» и «семейная ипотека → кредит
  магазина». Нерелевантная новая публикация о лицензии банка останавливается до LLM.
- Передаются полные допустимые пути признаков. Однозначно пропущенный `company.`
  дополняется с записью в trace; содержание, цитаты и неизвестные поля не достраиваются.
- После воспроизведённых усечений DeepSeek границы draft/review изменены один раз с
  6144/4096 на 8192/6144. Общий cap остался 30; неполные ответы отклоняются.
- Отзывы действительно сохраняются, повторная отправка не создаёт дубль; доступны
  фактические агрегаты попыток, статусов, времени обработки и отзывов.

## Проверка живой модели

Два реальных материала загружены по официальному RSS и отдельным HTML-страницам.
Их не было среди исходных десяти новостей; исходный снимок не менялся:

- [Устойчивая инфляция, 14.10.2026](https://www.cbr.ru/press/event/?id=32908).
- [Семейная ипотека, 09.10.2026](https://www.cbr.ru/press/event/?id=32901).

| Компания / роль | Итог текущей проверки | Подход |
|---|---|---|
| U_1595 / CFO | complete, новый review approved | Полный прежний draft заново проверен, путь кредитного признака дополнен |
| U_1595 / CEO | complete, новый review approved | Полный прежний draft заново проверен текущими правилами |
| U_83932 / CFO | complete, новый review approved | Полный draft, чей прежний review усёкся, проверен заново |
| U_83932 / CEO | complete, новый draft и review approved | Полная генерация на новой новости |
| U_83932 / CEO, вопрос о плане продаж | answered, review approved | Отдельное пояснение по источникам основного результата |

Старые approvals не использованы. В интерпретациях сохранены неизвестные данные компании,
условия переноса и даты банка. Для строительства проверена полная страница тактического
обзора: она действительно обсуждает потребительский спрос и рыночную ипотеку, но не
устанавливает показатели конкретного застройщика. Следующий шаг — доля семейной ипотеки
и сроки кредитов покупателей. Для розницы — закупки, цены, оборот и наличие договора.

В дополнительной приёмке сделано **16 физических генеративных запросов**: 7 первоначальных
DeepSeek, 2 Gemma, 5 при окончательной проверке четырёх контекстов, 2 на пояснение.
Gemma вернула полные JSON, но они были отклонены; она не выбрана моделью по умолчанию.
В этом официальном периоде до приёмки были ещё 4 запроса предыдущего аудита: всего 20
на момент завершения живой проверки. Стоимость в рублях неизвестна. Cap, ключ и серверные
ограничения бюджета не сбрасывались и не обходились. Локальный инженерный предел этой
фазы — 18, использовано 16. Смена модели не создавала отдельный счётчик.

Доказательства: `data/production_live_2026-10-23.json`,
`data/production_live_gemma_2026-10-23.json`,
`data/production_live_final_2026-10-23.json`, `data/production_holdout_2026-10-23.json`.

| Критерий ТЗ | Оценка и доказательство |
|---|---|
| 1. Релевантность | Реализована: известные признаки, роли, причины; исправлены два ложных переноса. Эвристика, не вероятность |
| 2. Интерпретация | Четыре проверенных результата, условные механизмы и конкретные действия; частные показатели не выдумываются |
| 3. Мнение банка | Отдельный видимый датированный блок; проверены исходные полные страницы |
| 4. Отбор и происхождение | Поиск E5/BM25, даты, ID, OCR, PDF, цитаты, хеши; непроверенные OCR-числа ограничены |
| 5. Новая новость | Два реальных положительных материала вне исходного снимка и новый отрицательный случай |
| 6. Путь пользователя | Обзор → компания/роль → событие → анализ → источники → вопрос → следующий шаг; настоящий браузер |
| 7. Расширение | Модульные ingestion/ranking/tasks, общий fallback; правила новой отрасли требуют своей разметки |
| 8. Мониторинг | Настоящие отзывы и агрегаты, повторяемый контроль и экспертный протокол; репрезентативной продуктовой оценки пока нет |
| 9. Постоянный вход | Кнопка на обзоре и постоянная навигация проверены |
| 10. Уточнения | sources/missing_data/explain, свой вопрос, OCR/PDF; живое пояснение прошло review |
| 11. Агент | Собственные план, инструменты, локальная проверка, review, revise/replan/stop; технический сбой отделён от нехватки данных |
| 12. Трассируемость | Признаки, даты, источники, этапы, ошибки, usage и история; ключ и скрытые рассуждения не публикуются |

Моя оценка готовности конкурсной сборки — **8/10**. Это субъективная инженерная оценка,
не вычисление балла жюри. Рабочий путь и поставка подтверждены. Основные ограничения
для более высокой оценки — два профиля, один издатель, датированный банковский корпус,
маленькая ручная выборка и ограниченная глубина использования графа связей.

## Проверки воспроизводимости

133 Python и 38 JS-проверок; 12 проверок корпуса и 13 содержательных контролей качества.
На восьми выбранных тематических запросах правильная страница в top-5 найдена в 5/8
случаев lexical, 8/8 semantic и 8/8 hybrid; три посторонних запроса отсеяны. Это маленькая
контрольная выборка, не оценка статистической точности.

Docker: сборка, non-root UID 10001, doctor/pip check, все 133 Python-теста в Linux,
настоящий HTTP без ключа, поиск и реальный restart с сохранённым томом. История и отзыв
сохранились, незавершённое задание стало failed, новых LLM-запросов не было.
Отчёт: `data/production_docker_2026-10-23.json`.

Дополнительно воспроизведено изменение хеша токенизатора при Windows Git-checkout с
автоматической заменой переводов строк. `.gitattributes` сохраняет исходные байты.
Настоящий checkout с `core.autocrlf=true` восстановил LFS-веса, совпал по байтам со всеми
проверяемыми исходниками и прошёл doctor без ключа. Отчёт: `data/production_git_2026-10-23.json`.

Браузер: ширины 1440/1024/768/390, без горизонтального переполнения; OCR-диалог и Escape,
вход с обзора, сохранение компании/роли, продолжение фонового задания и настоящий отзыв.
Отчёт: `data/production_browser_2026-10-23.json`, снимки в `docs/screenshots/production_2026-10-23/`.
Отзыв инженера обозначен как приёмка; он не выдаётся за исследование пользователей.

Результат чистой распаковки, установки зависимостей и повторных проверок фиксируется
в файле `.verification.json` рядом с передаваемым архивом. В поставку не входят `.env`,
ключ, runtime-БД, кеши, старые ZIP, dev-инструменты и личные настройки.
